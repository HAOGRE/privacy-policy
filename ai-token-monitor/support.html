常见问题

为什么看不到今日用量或 30 天趋势？

今日用量和 30 天趋势属于订阅或终身解锁功能。购买后请点击恢复购买，并确认当前 Apple ID 与购买时一致。

为什么应用没有读取到用量数据？

请确认你已经在应用中授权访问正确的本地用量数据文件。AI Token Monitor 只读取你主动选择的本地文件。

应用会上传我的 API token 或用量数据吗？

不会。AI Token Monitor 在本机处理数据，不收集、不上传、不共享你的 API token、用量数据或个人信息。

如何恢复已购买的订阅或终身解锁？

打开购买页面，点击“恢复购买”。如果仍未恢复，请确认网络连接和 Apple ID 后重试。

如何取消每月订阅？

请在 App Store 的账户订阅管理页面取消订阅。订阅和付款均由 Apple 处理。

FAQ

Why can't I see today's usage or the 30-day trend?

Today's usage and the 30-day trend require an active subscription or lifetime unlock. After purchasing, use Restore Purchases and make sure you are signed in with the same Apple ID.

Why isn't the app reading my usage data?

Please make sure you have granted access to the correct local usage data file. AI Token Monitor only reads local files that you explicitly select.

Does the app upload my API token or usage data?

No. AI Token Monitor processes data locally on your Mac and does not collect, upload, or share your API token, usage data, or personal information.

How do I restore a subscription or lifetime unlock?

Open the purchase page and click Restore Purchases. If it still does not restore, check your network connection and Apple ID, then try again.

How do I cancel the monthly subscription?

Manage or cancel the subscription from your App Store account subscription settings. Subscriptions and payments are handled by Apple.

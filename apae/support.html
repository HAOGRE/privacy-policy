常见问题

应该选择哪种设置方式？

管理自己的设备时，选择“我自己”，使用普通 Apple 账户批准个人“屏幕使用时间”授权。个人模式无需家长 PIN，你可以自行撤销权限或删除 Apae。管理孩子的设备时，选择“孩子”；设备需要登录家庭共享中的儿童 Apple 账户，由家长或监护人完成授权，再创建本机家长 PIN。儿童模式提供只读首页和普通“屏幕使用时间”防卸载保护。两种模式不会自动切换。

规则已开启，为什么应用没有受限？

先确认已完成 Apple 的“屏幕使用时间”授权；如应用提示权限问题，请按提示检查系统设置。再检查规则是否选中了目标应用并已开启。时段需处于所选星期和时间范围内；跨午夜时段按开始的星期计算。每日限额需在有效星期累计用完所设时长才会生效。应用受限时，打开它会显示“屏幕使用时间”的限制画面。提醒阈值只更新 Apae 内的状态，不限制应用，也不发送系统通知。

系统回调可能延迟，Apae 不承诺固定秒数内生效。重新打开 Apae，查看“设置”中的“运行状态”，按页面提示处理问题。重新授权后，需要重新选择各条规则的应用并开启规则。

如何解除某个应用的限制？

在“规则”页关闭对应的时段或每日限额；儿童模式需由家长输入 PIN 进入管理后操作。关闭会保留规则，删除会移除规则。Apae 会重新评估全部有效规则；如果另一个时段或已用完的每日限额仍覆盖该应用，它会继续受限。要解除 Apae 对某个应用的所有限制，请检查并关闭所有覆盖它的规则，而不只是其中一条。

忘记了 PIN 码怎么办？

个人模式不使用家长 PIN。儿童模式的四位家长 PIN 由家长在 Apae 中创建，与 Apple 的“屏幕使用时间”密码不同。更改 PIN 需要先验证当前 PIN。如果忘记了仍有效的 PIN，Apae 没有自助“忘记 PIN”重置入口，请通过下方邮箱联系支持；我们无法读取或远程重置本机 PIN。多次输错后，请等待界面显示的锁定时间结束再重试。请勿在邮件中发送 PIN 或 Apple 账户密码。

应用提示家长 PIN 需要重新设置怎么办？

这表示已保存的 PIN 无法使用，与单纯忘记 PIN 不同。仅在 Apae 明确显示此提示时，由家长按应用内说明在系统设置关闭 Apae 的“屏幕使用时间”权限，回到 Apae 完成重新授权，再设置新的 PIN。重新授权会清空原规则的应用选择并关闭规则，需要重新选择应用后开启。如果提示 PIN 暂时不可用，请稍后重试；不要将撤销权限或卸载应用当作常规的忘记 PIN 处理方式。

Apae 会上传我的数据吗？

Apae 的规则、应用选择和限额状态保存在当前设备，家长 PIN 保存在设备钥匙串中。Apae 没有自己的账号、服务器、云同步或远程家长端；授权由 Apple 的系统界面处理。在另一台设备上联系家长不会自动批准本机加时间。通过邮件联系支持时，只需提供设备型号、系统版本、Apae 版本和具体问题，不要发送 PIN、账户密码或其他敏感信息。

FAQ

Which setup mode should I choose?

For your own device, choose For Myself and approve individual Screen Time access with a regular Apple Account. Self mode has no parent PIN, and you can revoke access or delete Apae. For a child's device, choose For a Child. The device must be signed in to a child Apple Account in Family Sharing; a parent or guardian authorizes access, then creates a local parent PIN. Child mode provides a read-only home and ordinary Screen Time app-removal protection. Apae does not switch between these modes automatically.

Why isn't an app restricted when a rule is on?

First, check that you completed Apple's Screen Time authorization. If Apae reports an access problem, follow its instructions to check system settings. Then make sure the rule includes the intended apps and is on. A schedule applies on its selected days and during its time range; an overnight schedule belongs to the day it starts. A daily limit applies only after its shared allowance is used on an active day. When an app is restricted, opening it shows a Screen Time restriction screen. A warning threshold only updates the status in Apae; it does not restrict apps or send a system notification.

System callbacks may be delayed, so Apae does not promise a fixed number of seconds. Reopen Apae and check Status in Settings, then follow any instructions shown. After reauthorizing access, select apps again for each rule and turn the rules back on.

How do I lift a restriction on an app?

Turn off the relevant schedule or daily limit on the Rules tab. In child mode, a parent must enter the PIN first. Turning a rule off keeps its settings; deleting it removes the rule. Apae re-evaluates all active rules. If another schedule or an exhausted daily limit still covers the app, it stays restricted. To remove all Apae restrictions for an app, check and turn off every rule that covers it.

I forgot my PIN. What should I do?

Self mode does not use a parent PIN. In child mode, the parent creates a four-digit PIN in Apae; it is separate from Apple's Screen Time passcode. Changing it requires the current PIN. If you forget a valid PIN, Apae has no self-service forgotten-PIN reset. Contact support below; we cannot read or remotely reset the PIN on your device. After repeated incorrect attempts, wait for the lockout shown in the app before trying again. Do not send your PIN or Apple Account password by email.

Apae says the parent PIN needs to be set up again. What now?

This means the stored PIN is unusable, which is different from forgetting it. Only when Apae explicitly displays this message should a parent follow its instructions to turn off Apae's Screen Time access in system settings, return to Apae, authorize access again, and create a new PIN. Reauthorization clears the app selections in existing rules and turns those rules off; select apps again before turning the rules on. If the PIN is temporarily unavailable, try again later. Revoking access or reinstalling is not a routine forgotten-PIN recovery method.

Does Apae upload my data?

Apae stores rules, app selections, and limit status on the current device, and the parent PIN in the device's Keychain. Apae has no account service, server, cloud sync, or remote parent app. Apple handles authorization through its system interface. Contacting a parent on another device does not automatically approve extra time on this device. When emailing support, include only your device model, OS version, Apae version, and a description of the problem. Do not include PINs, account passwords, or other sensitive information.
